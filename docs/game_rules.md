# 9×9 보드게임 규칙

사용자가 2026-10-02에 제공한 규칙과 후속 확정을 저장한 문서다. 엔진의 규칙 구현과 테스트는 이 문서를 기준으로 한다. 후속 확정 사항은 마지막 절에 기록하며, 일반 바둑 규칙을 임의로 추가하지 않는다.

## 1. 목표와 준비

- 두 플레이어가 자신의 돌을 놓아 상대보다 넓은 집을 확보하거나, 상대 돌을 포위하여 승리한다.
- 보드: 9행 × 9열, 총 81개 착수 지점. 문서의 좌표는 1부터 센다.
- 선공: 흑 / 파란색, 돌 41개. 후공: 백 / 주황색, 돌 41개. 두 색 표현은 같은 선후공을 가리킨다. 최초 40개에서 사용자 후속 지시로 각자 41개로 변경했다.
- 기본 중립 돌: (5행, 5열)에 1개 고정된다. 어느 플레이어의 소유도 아니고 파괴할 수 없으며, 벽으로 사용할 수 있다.

## 2. 턴과 착수

- 선공부터 시작하여 번갈아 빈 지점에 자기 돌을 1개 놓는다.
- 돌을 놓고 싶지 않거나 놓을 곳이 없다면 패스할 수 있다.
- 이미 완성된 상대 집에는 착수할 수 없다.
- 이미 완성된 자기 집 안에도 착수할 수 없다. 즉, 어느 플레이어의 완성된 집에도 새 돌을 놓을 수 없다.
- 상하좌우만 연결로 인정하며, 대각선은 연결로 인정하지 않는다.
- 자충수는 허용하되 즉시 패배한다. 상대를 포획하지 못하면서 자기 돌 또는 연결된 자기 돌 무리의 마지막 빈틈을 스스로 막으면, 착수를 수락하고 상대 승리로 즉시 종료한다.

## 3. 집

- 자기 돌로 상하좌우를 빈틈없이 막아 둘러싼 안쪽 빈칸이 자기 집이다.
- 여러 칸을 둘러싸면 조건을 만족하는 안쪽 빈칸을 모두 센다.
- 보드 가장자리와 중립 돌을 벽으로 활용할 수 있다.
- 자기 돌의 경계 없이 보드 테두리만으로 이루어진 공간은 집이 아니다.
- 보드 가장자리의 4개 변을 모두 이용해야 둘러싸이는 영역은 집이 아니다. 1개, 2개 또는 3개 변을 이용한 집은 인정된다. 1개 변의 허용은 사용자 후속 지시로 확정했다.
- 집으로 인정하려는 영역 내부에 상대 돌이 하나라도 있으면 그 영역은 집이 아니다. 경계로 분리된 다른 영역은 독립적으로 인정될 수 있다.
- 중립 돌을 집 안에 포함시켜 둘러쌀 수 있다. 점수는 안쪽 **빈칸 수**이므로 중립 돌 자체는 점수에 포함하지 않는다.
- 집이 닫히는 순간 영구적인 소유자의 땅이 되며, 상대는 그 안에 새 돌을 놓을 수 없다.

## 4. 상대 돌 포위: 즉시 승리

- 상대 돌 1개 또는 상하좌우로 연결된 상대 돌 무리를 빈틈없이 포위하면 즉시 승리한다.
- 포획 후 대국을 계속하지 않는다. 단 1개의 상대 돌이라도 잡히면 즉시 종료된다.
- 상대 돌 무리에 빈틈이 하나 이상 남아 있으면 포획되지 않는다.
- 한 번의 착수로 양쪽 돌 모두가 파괴되는 상황이라면, 착수한 플레이어의 돌은 유지하고 상대 돌만 파괴한다. 따라서 착수자가 즉시 승리한다.
- 상대 포획을 자충수보다 먼저 판정한다. 상대 포획이 없을 때만 자충수에 따른 착수자 패배를 적용한다.
- 중립 돌은 포획 대상이 아니다.

## 5. 종료와 점수

- 상대 돌을 포위하면 즉시 종료되며 포획한 플레이어가 승리한다. 집 점수나 덤은 이 승리를 뒤집지 않는다.
- 상대 포획 없이 자충수를 두면 즉시 종료되며 상대가 승리한다.
- 두 플레이어가 연속으로 패스하면 종료되어 각자의 완성된 집 안쪽 빈칸 수를 센다.
- 선공의 집이 후공보다 **최소 3칸 많아야** 선공이 승리한다.
- 판정식: `선공 집 - 후공 집 >= 3`이면 선공 승리, 그 외에는 후공 승리. 무승부는 없다.

| 선공 집 | 후공 집 | 결과 |
| ---: | ---: | --- |
| 15 | 12 | 선공 승리 |
| 15 | 13 | 후공 승리 |
| 10 | 10 | 후공 승리 |

## 6. 숙련자 변형

게임 준비 단계에서 다음 변형을 선택할 수 있다.

- 선공이 중립 돌의 위치를 정한다.
- 중립 돌을 사용하지 않는다.

기본 규칙은 중앙 (5,5)에 고정된 중립 돌 1개다. 중립 돌을 옮기거나 사용하지 않는 변형에도 각자 41개의 돌을 적용한다.

## 7. 사용자 제공 예시 원문

`x`는 선공 돌, `o`는 후공 돌, `v`는 중립 돌, `.`은 빈칸이다. `H`는 설명에서 집으로 표시한 빈칸이다. 아래 그림은 원문의 행 길이와 기호를 그대로 보존했다. 작은 그림은 규칙 설명용이며, 실제 기본 보드는 9×9다. 원문의 `h`는 의미를 임의로 변경하지 않았다.

### 7.1 한 칸 집

```text
.........
....x....
...x.x...
....x....
.........
....v....
.........
.........
.........
```

네 개의 `x`가 상하좌우로 둘러싼 가운데 빈칸 1개가 선공의 집이다.

### 7.2 여러 칸 집

```text
...x.....
..x.x....
.x..x...
.x..x....
..xxx....
....v....
.........
.........
.........
```

원문의 설명: 안쪽 빈칸 5개가 모두 선공의 집이다. 세 번째 행은 다른 행보다 짧으므로 실제 테스트 보드로 옮길 때 좌표를 확인해야 한다.

### 7.3 완성된 상대 집 침투 불가

```text
.....
....x
...x.
..x..
.x...
```

후공은 이미 선공의 집인 3행 5열에 놓을 수 없다.

### 7.4 가장자리와 중립 돌 활용

```text
.....
...x.
..vHx
...x.
.....
```

```text
.....
.....
x....
Hx...
HHx..
```

```text
.......
...xx..
..vHHx.
..xHHHx
..xHHHH
..xHHHH
..xHHHH
```

세 그림의 `H`는 집으로 인정된다.

### 7.5 상대 돌 포함 불가, 중립 돌 포함 가능

```text
.......
...xx..
..x..x.
.x..ox.
.x...x.
..xxx..
.......
```

상대 돌 `o`가 포함된 영역은 집으로 인정되지 않는다. 실제 진행에서 포위가 완성되면 즉시 승리 규칙이 먼저 적용된다.

```text
.xHHH
.xHHH
.xHHH
oxHHH
.xHHH
```

왼쪽 영역에는 `o`가 있으므로 선공의 집이 아니며, 오른쪽 `H` 영역은 선공의 집이다.

```text
.......
..xx...
.xHHx..
xHHvx..
xHHHx..
.xxxx..
.......
```

중립 돌 `v`를 둘러싸더라도 `H` 영역은 집으로 인정된다.

### 7.6 가장자리 4변을 모두 이용한 집 금지

```text
.....
.....
x....
Hx...
HHx..
```

2개 변을 이용하는 `H` 영역은 집이다.

```text
HHxoh
HHx.o
HHx..
HHx..
HHx..
```

3개 변을 이용하는 `H` 영역은 집이다.

```text
..xoh
...xo
....x
.....
.....
```

`.` 영역은 4개 변을 모두 이용해야 둘러싸이므로 집이 아니다.

### 7.7 빈틈이 있으면 포획되지 않음

```text
.....
..x..
.xo..
..x..
.....
```

```text
.......
...xx..
..xo.x.
.xo..x.
.xooox.
..xxx..
.......
```

위처럼 빈틈이 하나 이상 있으면 상대 돌 또는 무리는 파괴되지 않는다.

### 7.8 양쪽 모두 포위되는 착수

착수 전:

```text
..xo.
..xox
...xo
.....
.....
```

착수 후:

```text
..xox
..xox
...xo
.....
.....
```

선공이 1행 5열에 `x`를 놓았을 때 양쪽 돌 모두 파괴 조건을 충족하더라도, 선공 돌은 유지하고 상대 돌만 파괴한다.

## 8. 후속 확정

사용자가 후속으로 확정한 규칙: 자기 집 안 착수 금지, 각자 돌 41개, 가장자리 1개 변을 이용한 집 인정, 자충수 허용 후 즉시 패배. 엔진과 테스트의 기본값에도 반영한다.

자충수는 상대를 포획하지 못하면서 자기 돌 또는 연결된 자기 돌 무리의 마지막 빈틈을 스스로 막는 착수다. **자충수는 허용하고, 착수자가 즉시 패배한다.** 양쪽 동시 포위 시에는 상대 포획을 먼저 판정하므로 착수자가 승리한다.

예시: 실제 보드 왼쪽 위 4×4 부분. `x`는 선공, `o`는 후공, `A`는 착수 후보인 빈칸이다. 위쪽과 왼쪽은 실제 보드 가장자리이며 오른쪽과 아래쪽으로 보드가 더 이어진다.

```text
착수 전       A에 x 착수 후
oxo.          oxo.
oAo.          oxo.
.o..          .o..
....          ....
```

착수 전 1행 2열의 `x`는 2행 2열의 `A`에만 빈틈이 있다. `A`에 `x`를 놓으면 두 `x`가 연결되지만 그 무리의 빈틈은 0개가 된다. `o` 무리에는 다른 빈틈이 남아 있어 상대 포획은 일어나지 않는다. `A`는 기존 `x`가 포함된 영역이므로 후공의 완성된 집이 아니다. 이 착수는 허용되며, 선공이 자충수로 즉시 패배하고 후공이 승리한다.

원문 예시 좌표 관련 참고: 일부 그림은 행 길이가 다르고, 9×9 그림의 중립 돌이 (5,5) 밖에 있다. 실제 테스트에서는 원문의 의도를 보존하면서 설명용 보드와 기본 게임 보드를 구분한다.
