# 저장한 학습 모델과 직접 대국하기

`examples/play_ai.py`가 저장한 정책·가치 신경망과 PUCT로 사람 대 AI 대국을
진행한다. 실제 보드와 착수 판정에는 기존 C++ 엔진을 사용하며 `engine/`는
변경하지 않는다. CPU와 CUDA를 지원하고 대국에서는 루트 잡음 없이 가장
많이 방문한 수를 선택한다. CUDA 설정에서는 규칙·트리·추론의 GPU PUCT를
사용하고 실제 착수를 기존 CPU 엔진에 적용한다.

## 현재 저장 파일

현재 환경에서 검증 학습을 저장한 폴더는 저장소 아래
`runs/gpu-trainer-validation-2026-10-05`다.

| 파일 | 용도 |
| --- | --- |
| `latest.pt` | 학습 재개: learner·champion·Adam·학습 버퍼·설정·진행·난수 |
| `best.pt` | 대국에 불러올 현재 기준 모델 champion 가중치 |
| `metrics.jsonl` | 완료 반복의 손실·평가·생성 자료 수·시간 |

현재 완료한 학습은 3회 반복, 자가 대국 384판, 가중치 갱신 24회다.
`latest.pt`의 CPU FIFO 버퍼에는 최신 착수 전 위치 10,000개가 들어 있다.
각 위치는 보드 입력·합법 수·탐색 방문 정책·최종 승패 목표·착수 플레이어를
포함한다. 버퍼가 가득 차면 오래된 위치부터 교체하며 전체 대국의 기보를
별도 파일로 계속 누적하지 않는다. 버퍼와 전체 학습 상태는 완료 반복
경계에서 저장한다.

현재 `best.pt`는 두 번째 반복에서 승격된 기준 모델이다. 세 번째 반복의
learner는 평가를 통과하지 않아 두 모델의 가중치는 다르다. 이 모델들은
짧은 연결 검증 학습의 결과이며 기력을 검증한 모델은 아니다.

배치 128·256·512·1024 비교 실행은 설정마다 임시 Trainer를 사용해
4096판의 처리량 지표를 JSONL로 기록했다. 그 실험의 버퍼와 갱신 모델은
별도로 저장하지 않았다. 일반 학습 실행은 `--output`으로 지정한 폴더에
위 세 파일을 저장한다.

## 시작하기

저장소 루트에서 가상환경의 Python으로 실행한다. 지정한 `best.pt`를 읽는다.

```powershell
.\.venv\Scripts\python.exe examples\play_ai.py --checkpoint runs\gpu-trainer-validation-2026-10-05\best.pt --human black --device cuda
```

사람이 선공 흑/파랑이고 AI가 후공 백/주황이다. 사람이 후공으로 두려면
`--human white`로 바꾼다. CPU로 대국하려면 `--device cpu`를 사용한다.
`--simulations`는 AI의 매 수 탐색 횟수이며 기본값은 128이다.
`--threads`는 CPU 연산 스레드 수이고 기본값은 1이다.
다른 학습의 모델을 상대하려면 `--checkpoint`에 해당 폴더의 `best.pt`를 넣는다.
`latest.pt`는 전체 재개 파일이므로 이 대국 실행기에 직접 넣지 않는다.

| 입력 | 동작 |
| --- | --- |
| `3 4` | 3행 4열에 착수. 행과 열은 1부터 9까지 |
| `pass` 또는 `패스` | 패스 |
| `help` 또는 `도움말` | 입력 안내 |
| `q` 또는 `종료` | 프로그램 종료 |
| 종료 후 `r` | 같은 모델과 새 대국 |

보드의 `x`는 선공 돌, `o`는 후공 돌, `#`는 중앙 중립 돌이다. `B`와 `W`는
각 플레이어의 완성된 빈 집이다. 거부된 착수는 사유를 표시하고 다시 입력을
받는다. 포획·자충수·연속 패스가 발생하면 승자와 종료 사유를 표시한다.
대국 동안 사용할 모델은 프로그램 시작 시 읽은 가중치로 고정된다.
학습에서 새 모델이 저장됐을 때는 프로그램을 다시 실행해 그 파일을 불러온다.
