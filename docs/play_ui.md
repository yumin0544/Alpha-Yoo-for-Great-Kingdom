# 클릭으로 플레이하는 Great Kingdom

Windows에서 저장소 루트의 **`PlayGreatKingdom.cmd`를 더블클릭**하면 로컬 게임
서버와 브라우저가 열린다. 기존 `.venv`의 Python, `my_board_engine` 바인딩과
PyTorch를 사용하므로 현재 프로젝트 환경에서 추가 설치가 필요 없다.
실행 창은 켜 둔다. 게임을 끝낼 때는 그 창에서 `Ctrl+C`를 누른다.

명령으로 실행하려면 저장소 루트에서 다음을 사용한다.

```powershell
.\.venv\Scripts\python.exe examples\play_ui.py --open
```

기본 주소는 `http://127.0.0.1:8765`다. 이미 사용 중이면 `--port 0`으로 빈 포트를
자동 선택한다. 더블클릭 실행기는 항상 빈 포트를 선택한다. 서버는 이 컴퓨터의
루프백 주소에서만 실행되며 외부 서비스와 통신하지 않는다.

## 플레이

- 빈 교차점을 클릭하면 현재 플레이어의 돌을 놓는다. 중앙 중립 돌, 기존 돌,
  완성된 집에는 클릭할 수 없다. 키보드는 보드에 Tab으로 들어간 뒤 방향키와
  Enter로 착수할 수 있다.
- 파랑은 흑/선공, 주황은 백/후공이다. 현재 차례, 남은 돌과 집 점수를 표시한다.
  마지막 돌에는 작은 흰색 표시를 남기고 최근 여섯 수를 화면에 보여 준다.
- **이번 차례 패스**로 차례를 넘긴다. 한 번 패스한 뒤에는 다음 패스가 대국을
  종료한다는 안내를 표시한다.
- **새 게임**은 현재 설정으로 다시 시작한다. 진행 중이면 실수로 대국을
  초기화하지 않도록 화면에서 확인한다.
- **대국 설정**에서 사람 대 AI 또는 두 사람 대국, 내 돌과 AI를 고른 뒤
  **이 설정으로 새 게임**을 누른다. 후공을 선택하면 AI가 먼저 둔다.
- **플레이 방법**에서 규칙을 확인한다. 포획은 즉시 승리, 상대 포획 없는
  자충수는 허용 후 즉시 패배이며 완성된 집에는 누구도 착수할 수 없다.
  두 번 연속 패스하면 파랑 집이 주황보다 최소 3칸 많아야 파랑이 승리한다.

기본 AI는 기존 C++ 순수 MCTS를 사용하며 모델 파일이 필요 없다. 저장한 AI를
상대하려면 목록에서 `runs/**/best.pt`의 모델을 선택한다. 시작 시 파일 목록을
읽는다. 모델 파일이 새로 추가되면 실행기를 다시 켜서 목록을 갱신한다.
가중치는 새 게임을 시작할 때 읽으며 대국 중에는 고정된다. `latest.pt` 같은
전체 학습 재개 파일은 목록에 넣지 않는다.

**AI 생각량**은 매 수 시뮬레이션 횟수다. 기본 64회, 선택 범위는
16·64·128·512회이며 큰 값을 선택하면 응답을 더 기다릴 수 있다.
기본 AI는 CPU 전용이다. 저장 모델의 GPU 선택은 PyTorch 신경망 추론을
CUDA로 옮긴다. 실제 규칙과 PUCT 트리는 기존 CPU C++ 경로에서 처리하고,
CPU 콘솔 상대와 같은 루트 전술 검사를 적용한다. 별도의 GPU 규칙·트리
경로를 사용하던 콘솔 `play_ai.py --device cuda`와 구별한다.

## 동작과 검증

`python/kingdom_ai/play_ui.py`가 대국 상태와 로컬 HTTP 연결을 관리하고,
같은 패키지의 `web/`에 화면 파일을 둔다. `examples/play_ui.py`는 모델 목록과
서버를 준비한다. `engine/`의 소스·규칙은 변경하지 않는다.

AI 로드와 탐색은 별도 작업자에서 실행하므로 보드가 응답한다. 생각하는 동안
착수는 잠기며 새 게임은 가능하다. 이전 탐색이 끝나도 새 판에 그 결과를
적용하지 않는다. 진행 중 탐색 자체를 강제 중단하지는 않으므로 새 AI 준비는
이전 작업 완료까지 기다릴 수 있다. AI 오류는 화면에 표시하며 다른 설정으로
새 게임을 시작하면 복구할 수 있다.

하나의 서버는 하나의 대국을 관리한다. 여러 탭은 같은 보드를 보여 준다.
화면 상태 번호와 서버 식별자를 확인하여 중복 클릭·오래된 탭의 착수가
다른 턴이나 서버 재시작 뒤의 새 대국에 적용되는 것을 막는다. 브라우저를
새로고침해도 서버가 실행 중이면 대국을 이어서 표시한다. 서버를 종료하면
대국은 사라지며 기보 저장·불러오기는 현재 제공하지 않는다.

`tests/play_ui_test.py`는 실제 착수·자충수·패스 종료, AI 턴, 진행 중 새 게임,
이전 작업 폐기, 오류 복구, 중복 요청과 로컬 HTTP 연결을 검증한다.
`BUILD_NEURAL_TESTS=ON` 구성에서는 CTest에도 등록한다.
