# 9x9 Board Game AI Engine

A high-performance C++ board game engine
with MCTS and neural network self-play.

## Features

- 9x9 board
- Custom territory rules
- Instant capture victory
- Pure MCTS
- Bitboard optimization
- PyTorch integration
- LibTorch inference
